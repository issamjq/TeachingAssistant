# 05 — Design system

The look is editorial, paper-like, calm. Cream backgrounds, hard contrast text, red italic accents on serif headings. Visual quality is a hard requirement — match references precisely.

## Two style systems, same brand

The app has two CSS systems that share the same hex values:

- **Studio** uses Tailwind v4 utility classes powered by `@theme` tokens in [`src/index.css`](../src/index.css) (e.g. `bg-paper`, `text-accent`).
- **Landing** uses raw class-based CSS in [`src/landing.css`](../src/landing.css) referencing CSS custom properties on `:root` (e.g. `var(--paper)`, `var(--accent)`).

Both define the identical palette below. If you change a hex, change it in both places.

## Color tokens

Defined in `src/index.css` under `@theme`. Tailwind v4 exposes them as `bg-*`, `text-*`, `border-*` utilities automatically.

| Token | Hex | Use |
|---|---|---|
| `paper` | #f4ede0 | Page background |
| `paper-warm` | #ede4d3 | Hover state, subtle elevation |
| `paper-cool` | #faf6ec | Card background, inputs, headers |
| `ink` | #1a1814 | Primary text, dark sidebar bg, primary buttons |
| `ink-soft` | #2d2a24 | Secondary text |
| `accent` | #c8472b | Brand red — italic emphasis, active states, links |
| `accent-soft` | #e87a55 | (reserved — softer red variant) |
| `gold` | #b8893d | Art subject; "Reuse this later" hints |
| `sage` | #6b7f5a | Science subject; "Ready to use" / success |
| `line` | #d4c9b3 | Card borders, dividers |
| `muted` | #6b6354 | Eyebrows, captions, metadata |

## Font tokens

Loaded via Google Fonts in `index.html`.

| Token | Family | Use |
|---|---|---|
| `font-serif` | Fraunces | Headings; use `<em>` for the italic accent word |
| `font-sans` | Inter Tight | Body, UI |
| `font-mono` | JetBrains Mono | Eyebrows, status pills, tags, metadata — always uppercase + tracking |
| `.arabic` | Amiri | Arabic text on the landing page (footer, hero card, RTL paragraphs). Studio doesn't use it yet. |

## Heading pattern

```jsx
<h2 className="font-serif text-4xl font-medium text-ink">
  Templates <em className="italic font-light text-accent">library</em>
</h2>
```

The italic-red accent word is the signature. One per heading.

## Eyebrow pattern

Small uppercase mono label, often above a heading or KPI:

```jsx
<p className="font-mono text-[10px] uppercase tracking-[0.18em] text-muted inline-flex items-center gap-2.5">
  <span className="w-6 h-px bg-accent" /> Templates
</p>
```

The 6px-wide red dash (`<span className="w-6 h-px bg-accent" />`) is the optional prefix. Use it on page-level eyebrows; omit it on small inline metadata.

## Status pill

1.5px dot of the relevant color + mono uppercase text inside a paper pill with a line border:

```jsx
<span className="inline-flex items-center gap-1.5 px-2 py-0.5 bg-paper border border-line text-ink-soft font-mono text-[9px] uppercase tracking-wider rounded-full">
  <span className="h-1.5 w-1.5 rounded-full bg-ink" /> In progress
</span>
```

Color the dot by status: `bg-ink` (in progress), `bg-sage` (ready), `bg-accent` (blocked), `bg-muted` (paused).

## Subject badge

2-letter mono code in a paper square with subject-tinted border. Generated by `_shared.jsx`'s `<SubjectBadge subject={...} />`. Subject → border color mapping lives there.

## Buttons

`src/components/ui/button.jsx`. Variants:

```jsx
<Button variant="primary">  // ink bg, paper-cool text — default
<Button variant="secondary"> // paper-cool bg, ink text, line border
<Button variant="outline">   // transparent bg, ink border
<Button variant="danger">    // accent (red) bg, paper-cool text
```

**Rule:** Never override `bg-*` or `text-*` via `className`. Tailwind class collisions can result in cream-on-cream invisible buttons. To customize, add a new variant in `button.jsx` instead.

## Cards

`src/components/ui/card.jsx`. `<Card>` is paper-cool bg with line border + rounded-xl. Pair with `<CardContent>` for default padding, or apply your own.

## Dividers

Dashed border-line dividers between rows:

```jsx
<div className="border-b border-dashed border-line" />
```

Solid `border-line` is for card edges and between major regions. Dashed is for subtle in-card row separators.

## Spacing rhythm

- Page padding: `p-8`
- Section spacing between header and content: `mb-8`
- Card grid gaps: `gap-4` to `gap-6`
- Heading-to-body gap: `mt-2`

## Common micro-patterns

- Italic red link: `text-accent hover:text-ink font-serif italic text-sm border-b border-accent hover:border-ink transition`
- Search input: `bg-paper-cool rounded-lg border border-line px-4 py-2.5` with a `<Search />` icon prefix.
- Drop-shadow / hard shadow: not in active use — when used, hard offset (no blur), ink-tinted. Reach for it sparingly.
